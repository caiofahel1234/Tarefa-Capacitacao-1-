# Dropkicks

Bem-vindo(a) ao repositório do projeto Dropkicks! Este README fornece informações detalhadas sobre o que é o projeto, como configurá-lo e usá-lo, e como contribuir.

☁ Visão Geral  
Dropkicks é um site para criação e personalização de tênis, onde os usuários podem escolher cores, materiais e estilos para criar seu próprio modelo exclusivo.

## Funcionalidades principais  
- Escolha e personalização de tênis com várias opções de cores e materiais.  
- Visualização em tempo real do tênis customizado.  
- Interface responsiva para desktop e dispositivos móveis.

## Tecnologias utilizadas  
- HTML, CSS (com Flexbox e Media Queries)  
- JavaScript para interação dinâmica  
- Fonte: Inter, via Google Fonts
